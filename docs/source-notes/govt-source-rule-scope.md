Kenny 2026-09-19 釐清 CLAUDE.md 第 0 節「唔用政府網做資訊來源」嘅範圍：**中共政府、香港政府、同中國盟友嘅政府**（俄羅斯、伊朗、北韓等）嘅官網、公報、官媒。

**Why:** 佢問「DW 係咪中共媒體」，我解釋 DW 係德國公共廣播並提到可能同「政府網」規矩衝突，佢即刻講明條規矩唔係針對呢類媒體。
**How to apply:** 唔好再因為「政府出資」而拒用或者留住 BBC、DW、NPR、France24、VOA、RFA 呢啲；VOA 中文已由「要用戶拍板」改做可用。判斷一個來源時問嘅係「係唔係北京陣營嘅政府／官媒」，唔係「有冇政府資金」。已寫入 CLAUDE.md 第 0 節同第 4 節 VOA 一段。
